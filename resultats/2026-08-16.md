## Limites

- **Aucune nouvelle annonce aimée à analyser** : l'API ne renvoie actuellement que
  **4 annonces sauvegardées**, toutes en *location*, et **toutes déjà présentes dans
  le cache `analyzedListings`** du profil location. Il n'y avait donc **aucune photo
  nouvelle à télécharger/analyser** ni thème inédit à intégrer. Les deux profils ont
  été **conservés à l'identique** (traits 📌 et `instructions` inchangés) avec le seul
  `updatedAt` porté au 2026-08-16.
- **Cache non purgé — décision assumée** : le profil *achat* conserve 35 annonces
  analysées (et le profil *location* 10) alors qu'elles ne figurent plus dans la
  liste des annonces aimées renvoyée par l'API. Purger ce cache aurait **effacé toute
  la base d'apprentissage** du profil achat (qui n'a plus aucune annonce aimée
  active), ce qui contredirait le principe de « modèle vivant, ne pas réinitialiser ».
  Ces entrées ont été analysées très récemment (2026-08-15) : elles ont donc été
  **préservées**. À revoir si l'utilisateur confirme les avoir volontairement retirées.
- **Achat = recherche sur la seule base du profil** (cas prévu : profil riche édité à
  la main, mais zéro annonce aimée active de ce type actuellement).
- **Liste noire très active** : sur les candidats location bruts de lesiteimmo,
  **73 sur 131 étaient déjà en liste noire** (55 %). Le vivier a été **filtré en amont**
  contre les 1 115 URLs exclues ; 2 candidats achat repérés (Le Bugue 24, Pinel-
  Hauterive 47) ont aussi été retirés car blacklistés. Résultat côté API : **0 candidat
  blacklisté** sur les deux envois.
- **Envoi achat** : 10 insérés / **5 ignorés** (URLs déjà présentes sur le site,
  probablement d'un envoi antérieur) ; envoi location : 16 insérés / 0 ignoré.
- **Caractère rare en location** : le marché locatif offre très peu de biens de
  caractère (pierre/poutres/tomettes) ; les filtres `maison-atypique`/`maison-belle-vue`
  de lesiteimmo renvoyaient 0 résultat en location, paruvendu était bloqué (403), et
  les recherches « maison de caractère à louer » ne remontaient que des pages d'index
  non vérifiables. La liste location est donc classée surtout sur les **traits fixés
  fonctionnels** (belle pièce à vivre, cuisine lumineuse, jardin, garage, entrée
  indépendante, salle de bain baignoire+douche, espace, calme) ; le cachet ancien,
  quand il manque, est **signalé honnêtement** dans chaque `reasons`. Les seuls vrais
  biens de caractère trouvés sont des **appartements anciens toulousains** (briques,
